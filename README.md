# Programacion3-PrimerEntregable-SharlotAdrian
Primer entregable - Sistema de Gestión Académica en Java

Nombre del estudiantes: Sharlot Adrián López.

Matricula: 1000-5786.

Materia: Programación 3.

Descripción del proyecto: Una institución académica necesita un sistema para administrar la información de sus estudiantes y materias.


El sistema deberá permitir registrar estudiantes, profesores y materias; asignar materias a estudiantes; registrar calificaciones; realizar búsquedas; y mostrar reportes básicos académicos.

La aplicación deberá funcionar completamente desde consola mediante un menú interactivo.


Tecnologias utilizadas: Java y Visual Studio Code.
